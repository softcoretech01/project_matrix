3. DATABASE ARCHITECTURE (15 Relational Tables)
--------------------------------------------------------------------------------
* projects        : Project code, name, description, owner, client, budget, status, reviewRequired
* tasks           : Task ID, title, description, project, assignee, assignedBy/createdBy, priority,
                    status, progress, start/end dates, dueDate, logged hours, completedAt
* subtasks        : Granular checklist items linked to tasks with live completion status
* task_comments   : Discussion comments, progress updates, and formal sign-off notes
* project_members : Project-level member allocation with assigned project roles
* project_sections: Functional modules/sections belonging to projects (e.g. Frontend, API)
* modules         : Core application modules linked to projects
* clients         : Client directory, contact person, email, country, status
* employees       : Official user accounts, designations, roles, departments
* allocations     : Team resource allocations & planned hours per project
* task_activity   : Real-time audit timeline of changes per task
* task_types      : Configurable task categories and classifications
* timesheets      : Work log hours, task linkages, submission status
* holidays        : Company & public holidays calendar
* leaves          : Employee leave requests and approval status

4. KEY FEATURES BUILT (Tasks & Projects)
--------------------------------------------------------------------------------
A. "ASSIGNED BY" TRACKING & VISIBILITY:
   - Every task captures the delegator (`createdBy`), showing exactly who assigned it.
   - Kanban Cards: Prominently displays `By: <Assignor>` badge on every task card.
   - My Tasks & Task List: Dedicated `Assigned By` column in both table views.
   - Task Details Modal: Highlights the assignor with full name and role badge.

B. CALENDAR PAGE - PURE MONTH GRID:
   - Streamlined into a pure month grid focused strictly on scheduling and deadlines.
   - Priority-based color coding (High: Rose, Medium: Amber, Low: Emerald).
   - Removed redundant "Add Task" buttons and toolbar clutter for distraction-free view.
   - 100% Theme-Adaptive: Integrated design tokens (`--card-bg`, `--bg-secondary`)
     ensuring flawless contrast in both Dark and Light modes.

C. UNIFIED DATE-MONTH-YEAR (DD-MM-YYYY) FORMATTING:
   - Project-wide standardization to Date Month Year (`DD-MM-YYYY`, e.g. `20-11-2026`).
   - Replaced browser-native UTC date string conversion with timezone-safe regex parsing
     to eliminate timezone shifts across all views.

D. PROJECTS MODULE:
   - Projects List: Search, filter by status, KPI summary cards, progress bars.
   - Auto-Generated Project Codes: Automatic PRJ-001, PRJ-002 codes generated by system.
   - Dynamic Delivery Progress: Progress bar auto-calculates from completed
     tasks ratio ((Completed / Total) * 100) with zero manual slider tampering.
   - Project Detail View:
     * Header with Project Code, Status badge, Quick Jump buttons.
     * Overview & Metrics tab (total, completed, in-progress, review, overdue).
     * Project Members tab (dynamic member addition & removal).
     * Sections & Modules tab (add, inline-rename, delete functional sections).
     * Daily Completed Tasks Tab: Chronological log of deliverables with exact
       completion date and timestamp.

E. TASKS MODULE (Integrated Sub-Views & Checklist):
   - 1. My Tasks     : Personal view filtered automatically by logged-in user.
   - 2. Task List    : Enterprise table with sorting, search, priority badges, and Assigned By.
   - 3. Kanban Board : Button-driven forward workflow ("Move to Next Stage")
                       instead of buggy drag-and-drop; displays assignor badge.
   - 4. Calendar     : Pure month grid mapping tasks to due dates with priority colors.
   - 5. Create Task  : Wide 2-column modal with Auto-Generated Task IDs (TSK-001)
                       and an interactive Employee Availability Matrix.
   - 6. Task Detail  : Interactive Subtask Checklist (dynamically updates progress %),
                       discussion comments, and completion timestamp tracking.

F. DAILY WORK LOG & REPORTS:
   - Dedicated "Daily Completed Deliverables" audit log showing what was completed
     each day with exact Date & Time stamp (e.g. 12-11-2026, 07:31 PM).
   - One-click CSV export for team reporting and management sign-off.

G. REVIEW & CLOSURE WORKFLOW (Role-Guarded):
   - Spec Page 11 compliance: Employees cannot self-close tasks.
   - Employee completes work -> Advances status to "Review".
   - PM / Admin reviews work in "Review & Closure" tab -> Signs off and closes task.
   - Automatically locks progress to 100% and timestamps completion.

H. RESPONSIVE DESIGN & ADAPTIVE SIDEBAR:
   - Screen <= 1024px: Sidebar automatically collapses into a sleek icon toolbar.
   - Screen > 1024px: Sidebar expands automatically with full menu labels.
   - Responsive multi-column layouts across all pages.
